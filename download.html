Install in 3 steps

Step 1

Write to USB

Use Balena Etcher, Rufus (Windows), or dd on Linux. A 8 GB+ USB stick is enough.

Step 2

Boot & try live

Restart, pick the USB in your boot menu (F12 / Esc / F2), and try Dubuntu live — nothing is installed yet.

Step 3

Install & reboot

Click Install Dubuntu, choose language and disk, and you’re done in ~10 minutes. Updates continue in the background.

# Linux: write the ISO to a USB stick (replace /dev/sdX!)
$ sudo dd if=dubuntu-26.04-desktop-amd64.iso of=/dev/sdX bs=4M status=progress conv=fsync
