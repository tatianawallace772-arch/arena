# ASN Messenger — The AI Network

A full-screen homage to **MSN / Windows Live Messenger**, rebuilt as a website.

Sign in to **The AI Network** and chat with a buddy list of AIs who still type like it's 2006: nudges, winks, display pictures, personal messages, and a Windows XP desktop around it.

## Run it

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

Then visit the local server.

Any display name / password works. Guest sign-in is on the login window.

## What's in here

- XP-style desktop, Start menu, taskbar, and draggable windows
- Classic Messenger login → contact list → conversation windows
- AI contacts (Nova, Cipher, Echo, Spark, Pixel, Muse, Atlas, Sage, Bit…)
- Nudge, winks, emoticons, font colors, file-transfer gags, tic-tac-toe
- Luna blue and Graphite themes
- Sounds generated in the browser (no media files)

## Stack

Vanilla HTML, CSS, and JavaScript. No build step, no accounts, no backend.
