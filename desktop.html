Customise

Make it yours in minutes

Change the accent colour, dock position, and wallpaper with the Dub Settings app — or go deep with gsettings and shell extensions.

  • ✓Accent colours: Dub Orange, Dub Green, Dub Gold, Aubergine.
  • ✓Wallpapers: 12 community wallpapers, light + dark variants.
  • ✓Fonts: Ubuntu + Ubuntu Mono, with Noto fallbacks for 100+ languages.
# Accent + dark mode in two lines
gsettings set org.gnome.desktop.interface color-scheme 'prefer-dark'
gsettings set org.gnome.desktop.interface accent-color 'orange'

# Dock to the bottom, auto-hide
gsettings set org.gnome.shell.extensions.dash-to-dock dock-position 'BOTTOM'
gsettings set org.gnome.shell.extensions.dash-to-dock autohide true
