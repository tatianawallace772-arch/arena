Desktop tour

A desktop that stays out of your way

GNOME 48 with the Dub Shell — familiar, fast, and easy to make your own.

Workspaces, dark mode & night light

Virtual desktops, system-wide dark mode, and a dock that auto-hides. Switch between light and dark with one click — Dubuntu remembers per-app.

  • ✓Fractional scaling for HiDPI laptops, no blur.
  • ✓Night Light and colour profiles built in.
  • ✓Accessibility: screen reader, magnifier, high-contrast.
# Switch to dark mode
gsettings set org.gnome.desktop.interface color-scheme 'prefer-dark'

# Enable fractional scaling (200%)
gsettings set org.gnome.mutter experimental-features ['scale-monitor-framebuffer']

Console that feels alive

GPU-accelerated terminal, sensible defaults, and dub — our helper for updates, codecs and drivers.

  • ✓One-command updates with rollback snapshots.
  • ✓Codec pack for MP3, H.264 and more, legally bundled.
  • ✓Driver helper for Wi-Fi and NVIDIA, no hunting.
$ dub update
✓ 128 packages updated · snapshot dub-20261124 created
$ dub codecs install
✓ Multimedia codecs installed
$ dub drivers check
✓ All drivers up to date

Every app, one place

The Dub Store searches Snap and Flatpak together. No duplicate results, no surprises — ratings and sizes up front.

  • ✓Curated collections for music, dev, and office.
  • ✓Offline updates — download once, install anywhere.
  • ✓Flatpak portal permissions explained in plain English.
$ snap install code --classic
$ flatpak install flathub org.gimp.GIMP
$ dub store search "music"
→ Dub Music · Spotify · VLC · Audacity
