Endpoints

GET https://ollama.com/v1/models — list models (OpenAI format)

POST https://ollama.com/api/show — model details (capabilities, context)

POST https://ollama.com/api/chat — chat (Ollama native, NDJSON)

POST https://ollama.com/v1/chat/completions — chat (OpenAI compatible, SSE)

Auth: Authorization: Bearer $OLLAMA_API_KEY

Tips

  • Cloud base is https://ollama.com — no local server needed.
  • For local, use http://localhost:11434.
  • Streaming is NDJSON for /api/chat and SSE for /v1/….
  • If you see CORS errors, run via a proxy or use ollama serve locally.
