Cloud-init

Automate first boot

Drop a cloud-config on your ISO or VM and Dubuntu configures itself — users, SSH keys, packages, and services.

  • ✓Hardened defaults: AppArmor, automatic security updates, auditd.
  • ✓ZFS + LUKS install options for encrypted roots.
  • ✓5-year LTS security updates from the Dubuntu archive.
#cloud-config
users:
- name: dub
sudo: ALL=(ALL) NOPASSWD:ALL
ssh_authorized_keys:
- ssh-ed25519 AAAAC3… you@host
packages:
- docker.io
- htop
runcmd:
- systemctl enable --now docker
